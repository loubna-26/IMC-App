# IMC-App

Aplicación Android para calcular el **Índice de Masa Corporal (IMC)** a partir del peso y la altura de la persona.

## Descripción

IMC-App permite introducir el peso (kg) y la altura (cm ) y muestra el resultado del IMC junto con su clasificación (bajo peso, peso normal, sobrepeso u obesidad). Es un proyecto de aprendizaje desarrollado con Android Studio.

## Ramas

- **main**: primera versión de la app (código original).
- **mejorar-ui**: nueva versión con la interfaz mejorada.
